# UI 规范

默认控制台为 `frontend/gpt2`，采用 React 19、Appica 1.3，视觉约定见 [gpt2 设计](../frontend/gpt2/DESIGN.md)。组件从子路径导入，颜色、边框、圆角和交互使用 Appica 角色变量。本文保留通用业务交互约定；旧前端的具体尺寸作为参考。

## 旧前端布局与文字参考

- 侧栏 224px、顶栏 56px；窄屏使用菜单抽屉。
- 页面外距 16px，桌面 24px；面板内距 16px，桌面 20px；面板间隔 16px。
- 顶栏显示页名，页面保留语义标题。工具栏按筛选、刷新和相关操作排列，允许窄屏换行。
- 正文与表格 14px，辅助值 12px，分组标题 16px，主数值 24px；数字使用等宽数字，命令和地址可选择复制。
- 标签到控件 8px，字段间隔 16px，分组间隔 24px；短表单限宽，配置表单使用响应式双列。
- 表格统一单元格留白、分隔线与悬停，操作列右对齐，数值右对齐；横向滚动限制在表格内。

防火墙顶部固定两层。第一层只放目标节点与地址族，节点最大 24rem、地址族最大 12rem，字段间距 16px，低于 640px 纵向排列。第二层左侧保留后端、应用状态与检查时间，右侧放刷新与设置，两组垂直居中，按钮使用 Appica md 的 40px 高度；低于 640px 时状态在上、操作在下，两组左对齐并间隔 12px。两层间隔 16px，分隔线位于第二层底部，错误提示单独排在其后。服务停用时显示停用状态；默认入站值留在编辑表单。分类页签与规则操作位于表格上方，窄屏换行。行操作保留查看，编辑、排序、删除放入更多菜单；空备注列隐藏，地址支持复制。

互信按来源节点分行，列为来源节点、IPv4、IPv6、操作；地址族筛选同时限制列与状态。地址旁显示实际状态，双栈结果不同时显示部分生效，检查时间集中显示。错误在详情中按运行和永久配置呈现。防火墙设置按目标节点展示双栈状态与汇总；开启确认说明互信公网 IP 优先放行全部主机入站端口，包含数据库端口及共享公网 IP 的其他来源。

## 状态与交互

主导航默认依次为概览、节点、容器、数据库、存储、防火墙、设置。“设置 → 外观”用上移、下移、恢复默认和保存调整七个菜单；桌面侧栏与移动端抽屉共用账号已保存顺序。其他会话更新时保留未提交编辑，版本冲突后重新读取再保存。“存储”独立页面当前显示未接入。

“设置 → API”提供独立开关、令牌列表和单表单创建；模板预填名称与权限，资源范围紧邻所属模块，有效期和来源 IP 放入可选设置。生成结果一次展示完整值，并提供地址、验证命令及 Prometheus 配置。列表菜单包含编辑、停用、重新生成和删除。

“数据库”按集群展示可用成员、代理与连接数；详情分为概览、成员、库、账号、代理和备份。接入表单完成节点选择、实例发现、连接补充和关联确认。库及账号表单直接选择所需代理，删除使用现有确认框；反馈沿用操作抽屉，展示各步骤与重新处理入口。节点自用 CouchDB 的分组名称为“OPSD 数据”。

容器页使用节点、容器状态和名称筛选，表格按容器、状态、节点、镜像、端口、操作排列，选择具体节点时隐藏节点列。容器名突出，Compose 项目和服务作为辅助信息；查看与日志直接提供，启停和重启放入更多菜单。筛选字段使用显式网格和 8px 标签间距，清除子项叠加外距，控件与刷新按钮均为 40px；1280px 起同排，640～1279px 两列，低于 640px 纵向排列且操作左对齐。详情使用右侧抽屉，日志使用独立对话框。未知受理结果提供“查询原操作”，容器需处理操作提供“核对状态”。部分节点失败与空容器列表分别展示，后台轮询保留当前内容。

`ui.tsx` 提供 PageToolbar、FormSection、StatusLabel、BusyButton、Failure、Confirm 和未提交修改保护。连接、配置、实际应用使用各自的业务状态。

首次加载保留字段、筛选和表头；数据位置使用骨架。后台刷新保留旧内容；手动刷新和提交保留动作名称并显示等待。错误提供相邻重试或核对入口。未知写入先查询原操作或目标状态。

对话框与抽屉采用 Header／Body／Footer；长内容在 Body 滚动，提交按钮通过 form 关联表单。确认框宽度 max-w-md，短表单 max-w-lg，规则和操作详情 max-w-2xl。关闭按钮使用中文名称，焦点由 Appica 管理。

页面只呈现字段、选项、操作、业务数据、必要状态与风险确认。公网缓存保留时间和已保存状态；缓存表单禁止提交。

## 检查范围

覆盖登录、概览、节点列表与详情、防火墙、设置和相关浮层；检查浅色、深色、系统主题，320／768／1440px、200% 缩放、长名称、IPv6、键盘、错误、空数据与等待状态。防火墙另查 639／640px 换行边界、1000px 中等宽度及 1920px 宽屏，分别核对筛选字段、状态与操作的对齐关系，并覆盖状态换行、加载和错误。实际结果见 VALIDATION.md。
