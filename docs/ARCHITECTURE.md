# 架构

`cmd/opsd` 是唯一程序入口。普通用户节点通过认证 Noise 通道管理成员、配置、目标队列、监控和可选控制台；root 执行器只监听本机 Unix Socket，接受类型化操作。

## 数据与执行边界

所属节点 SQLite 保存身份、配置、账号、成员目录、队列与待上传记录。地域 CouchDB 保存签名共享记录和历史，数据库内容用于查询与复制。目标操作在本机持久受理后串行执行；控制台、入口或共享数据库停止时，本机操作与恢复继续。

菜单顺序绑定所属节点的管理员账号，保存在独立的 `account_navigation` 表，版本与账号凭据分开。修改通过本机事务保存并向当前控制台会话发送 SSE，账号改名、改密及重启后保留；其他节点的管理员独立保存各自顺序。

`cluster` 负责节点协议和数据；`control` 负责会话、HTTP、SSE；`apiauth` 负责令牌摘要、生命周期与权限；`executor` 负责 root 服务；`operations` 负责独立执行与恢复；`firewall` 负责原生后端；`dockerengine` 负责本机 Docker；`databaseengine` 负责本机 MariaDB／ProxySQL；`monitoring` 负责采集。协议定义位于 `protocol`，HTTP 类型只从 `api/openapi.json` 生成。

防火墙后台检查在请求期限内等待本机操作锁，锁繁忙时保留上次实际状态；实际读取失败单独记录错误。互信维护与容器操作共用该锁，检查完成后继续按确认配置和实际互信覆盖受理迁移。

## API 与授权

API 和网页分别启停，共用现有 Web 监听；两者均关闭释放监听。成员通信、本机控制 Socket 与恢复进程独立运行。携带 Authorization 请求头时始终使用令牌认证；浏览器会话继续检查 CSRF。敏感管理接口仅接受管理员会话。

令牌所属节点保存随机值的摘要、授权与版本。任意入口每次请求经认证成员通道向所属节点核验一次，批量读取复用请求内结果；停用、过期、重新生成及撤销影响后续核验。所属节点离线返回 503。授权模块集中采用默认拒绝，列表先过滤再分页或汇总；地域范围按当前成员归属计算，节点与集群范围使用稳定 ID。

受理写操作固定令牌身份、目标及参数；幂等范围为令牌身份、目标与请求键，跨入口返回原操作。查询、取消、确认、重新处理和接受现状继承原操作的模块与资源权限。已持久受理的操作按固定参数继续，令牌撤销后拒绝新请求。

当前指标复用三秒读取缓存与并发合并，当前汇总按有效值计算。离线项保留最后采集时间。JSON 提供必要身份、读数、可达状态与检查时间；Prometheus／OpenMetrics 指标按监控、容器、数据库各自权限生成。历史继续每五分钟采集、保留七天；多节点查询可按节点返回，CouchDB 故障单独报告历史不可用。

## 数据库管理

集群定义由协调节点签名发布，通过成员目录传播；本机实例凭据及其历史版本只保存在所属节点 SQLite，密码使用现有密文机制。公开 HTTP 结构保留必要连接身份及状态。发现仅读取固定私有配置字面值与本机 Docker 配置；执行器只接受本机回环地址或绝对 Unix Socket。

数据库写入进入协调节点持久队列。受理时固定集群版本、合格成员及所选代理的连接版本；Galera 身份、Primary、Ready、Synced 与只读状态在执行前再次核对，业务变更执行一次。数据库层保护系统库、全局特权账号和登记的管理、监控、备份与 SST 账号。

`operations` 保存每一步准备状态、发送意图、读回和结果。代理写入依次修改内存、LOAD 到运行、SAVE 到磁盘，前后分别检查三层配置，其他待应用差异保留并返回冲突。删除账号先禁用所选代理，再删除 Galera 账号并清除代理记录。跨节点代理步骤进入目标节点队列，已完成步骤保留；协调节点中断后先查询原步骤，未知写入只读回，显式重新处理后才继续尚未执行步骤。凭据版本变化保留已受理操作所固定的版本。

备份页只读取既有计划、执行状态和目录产物。SQL 查询与表数据编辑交给外部工作台。OPSD 自用 CouchDB 归属“OPSD 数据”；后续 Silo 归属独立“存储”，低配置节点使用 S3 客户端，跨地域按桶异步复制。

## 容器

容器读取经节点认证 RPC 和类型化执行器消息到达目标本机，官方 Docker Go SDK 依赖留在 `dockerengine`。显式使用本机 Unix Socket 和 API 协商，支持 Linux rootful Docker；控制台及普通用户节点保持现有权限。旧 Portainer 转发方案作为历史设计。

资源由节点 ID、Engine ID 与完整容器 ID 定位，执行前再次检查。启动、停止和重启复用目标队列及独立操作服务，参数不可变；执行意图和 Docker 应答分别持久保存。重启成功要求已记录应答且读回新的启动时间。应答丢失或进程中断后只读回原资源，未知结果进入需处理；人工核对与接受现状保持原操作标识。防火墙的确认期限、定向撤销和确认配置独立运行。

列表按目标合并五秒内读取，日志合并两秒内读取；页面可见时轮询，日志采用有界尾部批次，最多 1000 行、256 KiB，TTY 与非 TTY 按 Docker 格式解码。读取使用限时请求和有界缓存；日志留在请求及短期缓存中。实际容器状态只通过所属节点获取，共享历史只保存操作记录。

Compose 容器允许单容器日常操作；Swarm 任务只读。OPSD 存储容器的启停由现有存储设置负责。部署、镜像更新、终端及 Docker 发布端口策略留待后续。

## 公网地址与互信

公网地址按 IPv4／IPv6 独立保存自动或手工模式、确认地址、观测、时间及错误；节点通信 URL 单独配置。新安装默认发现公网 IPv4，再尝试 IPv6，显式 `--address` 优先。自动模式启动、网络变化及每五分钟发现；每周期每地址族最多一次公共 HTTPS 回显和一次认证成员回显，绕过环境代理。

安装命令使用成员目录公布的通信 URL，保留固定版本脚本和 Noise 公钥。页面只生成下载、执行及短参数；系统准备和版本核验由发布脚本负责。`opsd network` 是持有节点及执行锁的本机维护入口，检查未结束操作，在节点服务停止时更新监听与通信模式，并同事务发布自身成员与配置记录。

一致结果更新地址；冲突和失败保留已有地址，手工模式保持人工值。所属节点签署地址记录，经认证目录传播。GET 优先读取目标，离线返回缓存标记。通信入站可达性由实际认证连接体现。

互信默认关闭，开关为集群签名策略。版本包含逻辑计数和发布节点 ID；并发同计数优先关闭，再按 ID 裁决。修改检查期望版本。全部有效成员（包含本机）的公网地址生成去重后的主机入站来源集合；共享 IP 保留全部有效关联节点，直到最后一个关联成员撤销或更换地址后移除。

普通节点持久化最新目标，root 执行器另存目标和实际状态，与普通操作共用写锁并独立维护：UFW 在 `before.rules`／`before6.rules` 保存自有 `OPSD_PEERS` 地址集合和加载引用，并在双栈 `INPUT` 首条维护带标记的运行跳转。互信来源命中后直接放行全部主机入站端口，其他来源返回现有外部规则及 UFW 普通规则。执行器启动和每五秒核对地址、跳转唯一性与位置，定向修复重复或后移的所属跳转；停用 UFW 时撤除所属运行规则并保留持久目标。原有外部链的内容及相对顺序保持原状。nftables 在可维护 input 基础链保存带标记规则，firewalld 使用自有 ANY→HOST 策略。普通规则导入、编辑与恢复保留互信区域。专用链中的外部规则或未知引用停止该部分改写并报告原因。

状态按地址族、运行与永久范围读回。关闭时撤除自有规则，离线节点恢复后继续；撤除未完成保留列表。Docker 发布端口策略与容器流量互信留待后续。

互信完成实际读回后，普通节点自动选择已管理入站规则中与成员精确 IP 相同、任意目标、任意协议、全部端口的允许条目，通过既有持久队列转交互信。节点在成功前保留原普通配置；执行器核对所需互信版本、运行与永久覆盖、普通确认配置及仅移除匹配条目的差异，按原有操作写锁执行并定向恢复。专用迁移信息仅用于该操作的校验，写入执行器确认配置时清除；`Automatic` 仍只恢复已确认配置。节点收到成功结果后同事务推进普通目标与确认配置。

迁移操作标识由互信版本、普通配置版本及规则集合确定。应答丢失查询同一操作，同输入失败停止自动重试；既有重试入口重新检查当前待迁移集合。迁移状态、操作 ID 及错误随普通防火墙状态保存，并在互信 GET 响应展示。转交后的规则随互信生命周期撤除，原普通条目保持移除状态。

运行时模型请求为零。
