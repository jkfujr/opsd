# OPSD 工作流

从项目根目录执行，先读取当前 `AGENTS.md` 和本任务涉及的改动，保留其他任务的工作。Go 模块位于 `backend/`；默认前端为 `frontend/gpt2`，分工及接入方式见 [前端开发](../../../frontend/README.md)。

- 只读审查：读取相关入口与现有运行结果，不改源码、不运行更新。
- 源码开发：按需读取 [开发参考](references/development.md)。HTTP 类型只改 OpenAPI 后生成，界面沿用当前 Appica。
- 界面布局、间距、状态与浮层采用 [UI 规范](../../../docs/UI.md)；公网地址与互信边界见 [架构](../../../docs/ARCHITECTURE.md)。
- CI 与固定版本发布：读取 [验收](../../../docs/VALIDATION.md) 和 [发布](../../../docs/RELEASING.md)，复用同提交成功工件。版本只改根 `package.json`，产物写入 `artifacts/`。
- 本地验收：复用输入未变的成功结果；运行用户要求的受影响测试。构建、接口应答、浏览器交互及实机恢复分别报告。
- 已授权部署：读取 [部署参考](references/deployment.md)，使用参数化辅助脚本。调用本 skill 不构成提交、推送或部署授权；已有明确授权持续有效。

当前为单个 `opsd` 程序的对等节点架构，不保留旧 Hub/Agent 兼容层。普通用户节点负责通信、配置、队列和可选控制台；root 执行器只监听本机 Unix Socket。全部控制台或数据库停止，已受理操作与本机恢复仍需继续。

互信来源包含本机及全部有效成员。普通精确 IP 的全入站允许规则在互信实际读回后，通过既有队列自动转交；关闭、撤销及地址替换随互信撤除。修改迁移逻辑时同时读取 `backend/internal/cluster/trust_migration.go`、执行器操作校验及 [架构中的恢复契约](../../../docs/ARCHITECTURE.md)，核对节点与执行器的确认配置，保留同输入失败后的停止自动重试行为。

UFW 互信在双栈 `INPUT` 首条通过所属跳转优先放行成员 IP 的全部主机入站端口，保留外部规则内容及相对顺序；持久文件保存集合与 UFW 加载引用。执行器启动与每五秒维护核对、去重并修复所属跳转，停用时定向撤除运行规则。检查地址集合及首条跳转后才记录生效；专用链中的外部内容保持冲突。互信页按来源节点合并双栈地址，设置页按目标节点展示双栈状态。

未知写入先查询原操作或目标现状，不自动重新提交。不得从 CouchDB 副本重放系统命令。界面只显示字段、操作、数据、必要状态与错误。

API 与网页独立启停，共用 Web 地址；令牌每次向所属节点核验一次，列表先按模块与资源过滤再分页，写入保持令牌身份、目标及请求键的幂等范围。敏感管理接口保留管理员会话。接入方式见 [API](../../../docs/API.md)。

数据库集群经协调节点管理，连接与凭据留在所属节点。MariaDB／ProxySQL 适配只在 `backend/internal/databaseengine`，执行器继续接受类型化本机步骤；Galera 变更执行一次，代理各步骤保留持久结果。未知结果先查原步骤，显式重新处理才继续；其他待应用代理差异保留现场。系统及登记的服务账号保持只读。“OPSD 数据”管理自用 CouchDB，后续“存储”使用 Silo。

容器操作由目标执行器经本机 Docker Unix Socket 完成，SDK 留在 `backend/internal/dockerengine`；使用节点、Engine 与完整容器 ID。重启发出前持久保存意图，应答未知只核对；容器的重新处理只读回状态，保留原操作。Swarm 任务只读，OPSD 数据库组件通过存储设置管理。镜像更新及 Compose 逐步保存意图，应答未知只核对原资源；Shell 任务按任务 ID 加锁，取消释放独立 systemd 进程组，终端使用独立认证数据通道并随管理员退出释放。公网切换使用停止服务后的 `opsd network`，读取实际通信及监听配置，防火墙端口由既有规则入口显式配置。

`.data` 保留为临时资料；其中的一次性日期、凭据、旧架构清理和历史成功结论不作为当前操作依据。运行时模型请求为零。
