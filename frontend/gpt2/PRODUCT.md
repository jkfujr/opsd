# OPSD Mosona 控制台主题

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

管理多台 Linux 服务器的管理员。桌面查看全局资源变化、定位异常，再进入节点、容器和终端工作；手机保留必要的查看与操作。

## Product Purpose

作为默认内置界面、独立可安装主题和内置恢复界面，管理 OPSD 已有能力。一级导航包含概览、节点、容器、数据库、存储、防火墙、工具和设置；工具包含终端与定时任务，设置包含账号、登录会话、API、外观和版本。

## Capabilities and Constraints

- React、TypeScript、Vite、Appica；图表使用 Recharts，终端使用 xterm.js。
- 统一同源调用 API v2，复用根项目生成类型、TanStack Query 和 openapi-fetch。数据、状态、操作及权限来自后端；缺失读数显示“—”。
- 终端每次连接申请一次性票据，使用 WebSocket JSON 帧与 Base64 字节协议；支持 ANSI、UTF-8、输入、尺寸、搜索和多会话。
- 浏览器刷新结束终端会话；跨业务页面保留实例、输出和滚动位置。重新连接申请新票据并保留旧输出，不重放输入；退出及会话失效释放连接。
- 写入不自动重试；应答未知保留非敏感请求引用，查询原回执或原操作。ETag 或资源版本冲突保留草稿并提供重新读取。
- 节点系统信息只读；节点配置、账号和公网地址分别调用已有接口。“OPSD 数据”归属节点配置；独立存储入口显示“未接入”。
- 容器不提供直接创建或任意修改镜像标签；Compose 使用服务端发现的目录和文件，配置文件编辑沿用 SSH。任务通过定义中的启用状态管理；备份只读，数据库保护账号只读。
- 主题格式版本为 1，API 版本为 2，login: theme；版本来自根 package.json。默认内置构建使用绝对资源路径，独立 ZIP 使用相对资源；恢复模式业务路由基址为 /__opsd/builtin，普通模式为 /。
- 恢复登录使用原安全入口加 ?builtin=1；退出、失效及账号修改后保留恢复登录模式。主题启用后，用户点击“刷新界面”进入所选主题的普通根路径。
- 部分分页失败保留有效内容和游标，提供继续读取。Problem 显示字段错误和请求 ID，429 按服务端时间等待。
- 字体随应用分发，保留 OFL 许可证与来源；终端字体进入工作区时加载。
- 外观与终端偏好使用 opsd.frontend-gpt2 命名空间保存。

## Brand Commitments

OPSD，简体中文。用户明确选择 Mosona Manager 后台与侧栏会话布局作为主要视觉参照，并要求更大的文字、控件与独立终端。中性黑白灰、清楚的名称与读数、明确面板边界；支持深色、浅色和跟随系统，默认深色，终端输出区始终纯黑。界面字体为 Inter + 思源黑体，终端字体为 JetBrains Mono + 更纱 Fixed SC。

## Product Principles

- 首页先呈现全局趋势，重要数据、异常与对应节点关系清楚。
- 放大内容与控件并重排字段，保留必要状态和单位。
- 相同动作使用相同控件；常用图标操作、创建与确认文字、按需菜单各有固定位置，颜色表达选择、状态和图表序列。
- 独立终端占满工作区，多会话切换不丢失当前内容。
