# OPSD Monitor

独立的多服务器管理后台视觉与交互原型。默认深色雾蓝，提供雾蓝、青绿、鸢紫、琥珀四种配色，以及深色、浅色和跟随系统模式。

## 启动

在本目录执行：

    npm ci
    npm run dev

访问 [本地原型](http://127.0.0.1:5180/)。端口固定为 5180，被占用时直接报错。

    npm run typecheck
    npm run build
    npm run preview -- --port 5181

构建文件位于被忽略的 dist/；依赖和临时验收文件同样被忽略。程序版本读取仓库根 package.json。

## 原型范围

- 概览：先显示资源趋势与需关注事项，下方为完整宽度的节点表；支持地域、状态与名称筛选、排序，独立选择节点预览并定位到趋势标题，24 小时／7 天与资源／网络切换。筛选与预览保存在地址中。手机直接显示节点资源，通过页签切换趋势。
- 节点：添加节点、详情与配置、演示终端、Shell 任务创建、运行、取消和日志。
- 容器：筛选、启停、重启、更新镜像、详情与日志，Compose 项目登记与启停；常用查看和日志直接提供，其他动作位于更多菜单。
- 数据库：集群接入与编辑，概览、成员、库、账号、代理和备份；保护账号只读。
- 防火墙：按节点和地址族查看规则、添加编辑删除、规则开关、集群互信与操作确认。
- 设置：演示账号与会话、API 开关与令牌、颜色模式与四种配色、菜单排序和版本。
- 存储：呈现 Silo 尚未接入的状态；OPSD 自用 CouchDB 位于节点配置。

页面上的“演示”按钮可切换标准、空数据、加载、部分失败和应答未知状态。快速查找支持 Ctrl+K 或 Command+K。

## 数据与状态

所有业务数据均为固定演示内容。域名使用 .example，IP 使用文档地址段。界面不发送后端 API 请求，终端不执行系统命令，安装命令和令牌均为演示值。

演示操作只修改当前页面会话的内存状态，刷新后恢复。颜色模式使用 opsd.frontend-gpt.theme，配色使用 opsd.frontend-gpt.palette 保存在当前浏览器；配色变化同步到同来源的其他标签页。保留已有颜色模式偏好，配色未保存时使用雾蓝。登录页、工作页面和浮层共用偏好，不读写旧前端配置。

所有页面、布局、样式和组件组合独立编写，未导入旧前端实现。基础交互使用 Appica；页面按路由加载。颜色变量集中在 src/palettes.css，布局与排版集中在 src/styles.css；产品事实见 PRODUCT.md，视觉规范见 DESIGN.md。

## 验证

验证输出位于本目录被忽略的 .impeccable/review/，一次性浏览器脚本位于仓库被忽略的 artifacts/frontend-gpt/。这些记录不作为真实服务器、后端联调或部署结果。

类型检查及生产构建通过。本轮重查首页与节点详情在深浅模式及 1920／1440／1024／768／390／320px 下的 24 个组合，另检查手机趋势视图；其他 160 个布局组合复用此前结果。页面溢出、脚本错误和非预期后端请求均为 0。1440×900 首屏完整显示监控区并能看到节点表开头，节点表自然向下延伸。

首页图表为 240px，手机端为 224px，加载占位使用相同高度；节点详情图表仍为 164px。已重查概览筛选、排序和图表切换，并检查预览定位与焦点、普通筛选和清除选择保持操作焦点、鼠标与键盘读数、长名称、详情往返、手机切换、加载、空数据、部分失败、离线，以及多条异常的区域滚动和操作入口。

其余 12 组业务交互、12 组浮层与状态检查，以及四种配色的颜色、文字对比度和外观偏好检查复用此前结果。此前主要文字与状态色对比度均达到 4.5:1，已检查主题刷新保持、跟随系统、登录前后一致、配色跨标签页同步和演示业务数据刷新恢复。

复用此前原生 200% 缩放结果：通过隔离 Edge 配置的默认缩放值设置，覆盖当时的 22 个页面及规则弹窗。1440px 视口读回 innerWidth=720、devicePixelRatio=2、visualViewport.scale=1、CSS zoom=1。结果位于 appearance-result.json；原型 UI 不包含此验证设置。

本轮设计规范和组件记录已根据实际代码刷新。未接入真实后端，未提交、推送或部署。
