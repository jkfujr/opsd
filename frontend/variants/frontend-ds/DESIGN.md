## World

三联单 / 货运单据。控制台是一张调度台：每台机器是一个承运点，每条变更是一张编号单据，签收之前都可以撤销。
纸面、墨色、等宽编号、骑缝线、印章。世界只提供四样东西：字体、配色、密度、一个签名动作（单据与签收章），
导航与控件保持 Web 平台的标准形态，不做制服的模仿。

实现位置：`frontend-ds/`。旧前端 `frontend/` 不再代表本设计系统。

- 中文：`Microsoft YaHei UI` / `PingFang SC` / `Hiragino Sans GB` 回落。

## Layout & density

- 外壳：`220px` 侧轨 + 纸面工作区；顶栏 `52px`；页面外距 `26px`（≤900px 时 `16px`）。
- 面板内距 `16px`；面板间隔 `12px`；页面纵向节奏 `18px`。
- 表格行高 `44px`，表头 `9px 14px`；数字右对齐，单据号等宽。
- 圆角只有两档：`2px`（控件）与 `3px`（面板）。没有 8px 以上的圆角，没有卡片投影，只有覆盖层用阴影。

## Copy discipline

界面上不写注释。这条是本系统的硬规则，来自对"标题 + 一行小注"这一生成式排版习惯的清理。

- **标题独立站立**：`h1` / 面板 `h2` 后面不挂副标题、kicker、英文小注或说明句。标题已足够，注脚只是噪音。
- **计数属于数据**，不属于标题：`待签收 3`、`操作记录 1` 里的数字是数据；`MANIFEST`、`PEER`、`REV 4`、`03 张` 这类标签不渲染。
- **状态用印章**：面板若需要表达状态（运行正常、待应用、离线），在头部右侧放 `Stamp`，不写文字说明。
- **解释只在不可逆处出现**：撤销节点、关闭互信、删除库/账号、接受现状、令牌只显示一次 —— 这些地方保留一句话，说明后果与恢复方式；其余一律删掉。
- **空态与错误**写"发生了什么、下一步做什么"，不写架构原理（对等、同事务提交、读回确认、采集间隔都不进界面，它们在 README 与 DESIGN 里）。


## Signature interaction

1. **单据落章**：任何一次写操作在概览、节点详情、操作队列里都呈现为一张带编号的单据；状态以印章表达，`待签收` 的单据左边缘染朱红并给出剩余秒数。
2. **存根齿孔**：单据左缘的打孔条是唯一的装饰性元素，它让列表读起来像一叠可以撕下来的联次。
3. **读数条**：指标卡把使用率压成 3px 的墨线，超过阈值才换色；趋势图用末端圆点标记「现在」。

## Motion

- 只保留三处：覆盖层 120–160ms 淡入/上浮、印章与单据无动画、图表数据 320ms 过渡。
- `prefers-reduced-motion` 下全部关闭；没有持续循环的装饰动画（骨架屏的 1.3s 扫描除外）。

## Responsive

- ≥1201px：指标 4 列，概览左右 1.62:0.9，节点详情双列。
- ≤1200px：指标 2 列，概览单列。
- ≤900px：侧轨变为抽屉，设置导航横向滚动，节点详情与趋势单列。
- ≤640px：指标单列，表单单列，防火墙筛选纵向排列。
- 320px 不出现横向溢出；表格自身横向滚动，不撑破页面。

## Voice

操作手册式的直接陈述，中文，短句，不用感叹号。术语固定：节点、成员、接入码、操作、确认、恢复、互信、集群、库、账号、代理、备份。
按钮用动词开头（「保存配置」「生成安装命令」「确认保留」），状态用名词（「待签收」「已同步」「需处理」）。
